# Full Stack Social Media Platform

Projenin amacı AWS servislerinin nasıl kullanıldığını, hangi servislerin gerektiğini, gerekli yapılandırmaların nasıl yapılması gerektiğini öğrenerek geliştirdiğim bir sosyal medya platformu.

## Kullanılan Teknolojiler
- Amazon Web Service(DevOps)
- Fast API Backend
- Next.js Frontend
